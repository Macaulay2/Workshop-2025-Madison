# Strategy for Constructing $H$ from $H_0$ (Greedy Template Reduction)

This summarizes the paper’s Section 4 strategy (built on Section 3) for turning an initial syzygy-based matrix $H_0$ into a modified matrix $H$ that yields a smaller elimination template.

## 1) Parameterize all valid $H$ around $H_0$

- You want a matrix $H$ such that the vector

  $$V = a\,v(\mathcal{B}) - T_a\,v(\mathcal{B})$$

  lies in the ideal generated by $F = \{f_1,\ldots,f_s\}$, i.e.

  $$V = H\,v(F).$$

- One valid choice $H_0$ can be obtained as a byproduct of Groebner basis computation (a “change matrix” / extended output).
- Let $H_1$ be any matrix whose rows generate the first syzygy module of $F$, i.e.

  $$H_1\,v(F) = 0.$$

- Then all matrices of the form

  $$H(\Theta) = H_0 + \Theta\,H_1$$

  also satisfy $V = H(\Theta)\,v(F)$ as long as $\Theta$ is a matrix of scalar parameters (the paper restricts to $\theta_{ij}$ in the base field).

The goal is to pick $\Theta$ so that the resulting elimination template (Macaulay matrix built from the shifts implied by $H$) becomes smaller.

## 2) Rephrase “small template” as “many zero shift-columns”

- Write the $k$-th column of $H$ as $h_k = Z_k\,c_k$, where:
  - $c_k$ is the monomial vector (the support of $h_k$),
  - $Z_k$ is the corresponding coefficient matrix whose entries are affine functions of the parameters $\theta_{ij}$.
- Concatenate these coefficient matrices into

  $$W = \begin{bmatrix} Z_1 & \cdots & Z_s \end{bmatrix}.$$

  Columns of $W$ are in 1-1 correspondence with shifts in the expanded system, hence with rows of the elimination template.
- Reducing the template is cast as: choose parameters to zero out as many columns of $W$ as possible (each zeroed column removes a shift / row).
- Pre-filtering: any column of $W$ that contains a nonzero scalar entry cannot be made identically zero by changing parameters; remove those columns from consideration.

## 3) Greedy parameter adjustment strategies

The paper proposes two greedy heuristics. In both, “zeroing out a column” means enforcing linear constraints that make that column of $W$ identically zero.

### A) Row-wise greedy (targets removing template rows)

- Let $w_k$ be the $k$-th column of $W$.
- To eliminate a shift, solve the linear constraints $w_k = 0$.
  Because each row of $W$ has its own parameters, $w_k = 0$ splits into $d$ independent scalar equations (one per row-block / per row of $H$).
- Define a score $\sigma(k)$: the number of columns of $W$ that become zero after adding the constraints $w_k = 0$.
- Greedy loop:
  1. Compute $\sigma(k)$ for all remaining columns.
  2. Pick $k$ with maximal $\sigma(k)$.
  3. Add constraints enforcing $w_k = 0$ (update parameter assignments / feasible space).
  4. Repeat while some $\sigma(k) > 0$.

Example. Suppose

```text
      col0    col1    col2
row0  t0+1    t0+1      0
row1  t1-2      0     t1-2
```

so

```text
W = | t0+1  t0+1   0   |
    | t1-2   0    t1-2 |
```

Start with no assignments, so $A = \emptyset$.

- Try zeroing `col0`. This requires
  $t_0 + 1 = 0$ and $t_1 - 2 = 0$, so $t_0 = -1$ and $t_1 = 2$.
  After substitution,

  ```text
  W = | 0  0  0 |
      | 0  0  0 |
  ```

  so all $3$ columns are zero. Thus $\sigma(0) = 3$.

- Try zeroing `col1`. This only requires $t_0 + 1 = 0$, so $t_0 = -1$.
  Then

  ```text
  W = | 0   0   0 |
      | t1-2  0  t1-2 |
  ```

  and only `col1` is guaranteed to be zero. Thus $\sigma(1) = 1$.

- Try zeroing `col2`. This only requires $t_1 - 2 = 0$, so $t_1 = 2$.
  Then

  ```text
  W = | t0+1  t0+1  0 |
      | 0      0    0 |
  ```

  and only `col2` is guaranteed to be zero. Thus $\sigma(2) = 1$.

The greedy choice is therefore `col0`, since it gives the largest score. The algorithm keeps the assignments
$t_0 = -1$, $t_1 = 2$, and then stops because every column of $W$ is already zero.

### B) Column-wise greedy (targets removing excessive monomial columns)

- Let $\mathcal{E}$ be the set of excessive monomials of the parametrized template.
- For each $e \in \mathcal{E}$, define $\mathcal{W}_e$ as the subset of columns of $W$ whose corresponding shifts contain $e$.
- Define a score $\sigma(e)$: the number of columns of $W$ that become zero after enforcing $w = 0$ for all $w \in \mathcal{W}_e$.
- Greedy loop:
  1. Compute $\sigma(e)$ for all $e \in \mathcal{E}$.
  2. Pick $e$ with maximal $\sigma(e)$.
  3. Add constraints enforcing $w = 0$ for all $w \in \mathcal{W}_e$.
  4. Repeat while some $\sigma(e) > 0$.

Notes:
- Column-wise is typically faster because it attempts to zero multiple shift-columns at once.
- Row-wise can yield smaller templates in some instances.
- The paper’s generator runs both strategies and keeps the smallest resulting template.

## 4) After choosing H

Once the greedy search fixes parameters (thus fixes $H$), build the elimination template from the shifts implied by the supports of the columns of $H$.

(Section 4 also describes additional, optional reductions applied *after* template construction: Schur-complement reduction (4.2) and removing dependent rows/columns (4.3).)
